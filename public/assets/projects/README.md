## 💡 Lưu ý tiện ích:
1. **Định dạng file:** Dùng `.jpg`, `.png`, `.webp` đều được 100%!
2. **Kích thước khuyến nghị:**
   * **PC / Web Desktop:** Tỷ lệ `16:9` hoặc `16:10` (khoảng `1920x1080` hoặc `1440x900`).
   * **Mobile App:** Tỷ lệ `9:19.5` hoặc `9:16` (khoảng `1080x2340` hoặc `1170x2532`).
3. **Tự động dự phòng thông minh (Fallback):** Khi bạn chưa chèn ảnh hoặc ảnh bị lỗi đường dẫn, hệ thống tự động hiển thị khung **BluePrint / Wireframe kỹ thuật** cực đẹp mà không bao giờ bị lỗi icon ảnh vỡ!
4. **Phóng to (Lightbox):** Nhấp chuột trực tiếp vào khung để mở ảnh toàn màn hình (Fullscreen) sắc nét.
